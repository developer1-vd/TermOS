# Phones the TermOS phone edition is built for, by Nura codename (Nura was
# formerly postmarketOS). Columns: codename, Nura category, phones.
#
# Some phones were made with different display panels and need the kernel
# for theirs: those have one entry (and one image) per panel, written
# codename:kernel. The Nura wiki page for the phone says how to tell which
# panel yours has.
#
# "community" devices are well supported by Nura; "testing" ones boot and
# mostly work, but expect rough edges (calls, camera, battery life). The list
# of what works on each phone is on the Nura wiki: https://wiki.nura.eco/
#
# Not possible: iPhones (Apple locks the bootloader; no Linux runs there) and
# the Samsung Galaxy Z Fold series (no Nura or mainline Linux port).
